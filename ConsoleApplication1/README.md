# 小さなコンソールRPG

課題の6つの技術を使ったC++のコンソールRPGです。
スライム・ゴブリン・ドラゴンを倒すとクリア、勇者のHPが0になるとゲームオーバーです。
攻撃ダメージと敵の行動がランダムに変わるので、予告と残りの資源を見てコマンドを選びます。

## 起動と操作

1. Visual Studioで既存の ConsoleApplication1 ソリューションを開きます。
2. Ctrl + F5でビルドして実行します。
3. 数字を入力し、Enterで決定します。

| 画面 | 入力 | 動作 |
| --- | --- | --- |
| タイトル | 1 / 0 | 開始 / 終了 |
| 戦闘 | 1 | 通常攻撃。気力が1回復 |
| 戦闘 | 2 | 回復薬。HP25回復 |
| 戦闘 | 3 | 防御。通常攻撃100%・大技50%軽減、気力+1。連続使用不可 |
| 戦闘 | 4 | 強攻撃。気力2消費、威力1.75倍、敵の防御を無視 |
| 戦闘 | 0 | 冒険を中断 |
| 結果 | 1 / 0 | もう一度遊ぶ / 終了 |

勇者はHP100・攻撃力12・回復薬2個・気力3で開始します。気力の上限は3です。
HP・薬・気力は次の敵との戦闘にも引き継ぎます。再挑戦時はすべて初期化します。
薬がない・HP満タン・気力不足などで行動できない場合や、入力ミスではターンを消費しません。
敵の予告も変更されないので、無効な操作を繰り返して都合のよい行動を引くことはできません。
勇者の防御は2ターン連続では使えません。間に通常攻撃・強攻撃・回復薬の使用を成功させると再び使えます。入力ミスや使えない薬・気力不足では、この禁止は解除されません。再挑戦時には解除されます。

## 毎回変わるもの

- 敵の最大HP：基準値の90～110%。小数点以下切り捨て。
- 両者の攻撃：基準威力の80～120%。10%で会心となり、さらに1.5倍。
- 次の敵の行動：敵ごとの確率で抽選し、コマンドを選ぶ前に予告。
- 再挑戦：新しい乱数を使い、前回と同じ戦闘を繰り返しません。

倍率の計算では整数の端数を切り捨てます。攻撃威力は最低1ですが、勇者が通常攻撃を防御した場合は0ダメージです。大技の防御ではダメージを半分にし、端数を切り捨てます。
敵が倒れたターンは反撃されません。防御と息切れの敵も反撃しません。

| 敵 | 基準HP | 実際のHP範囲 | 攻撃力 | 大技の抽選確率 | 防御の抽選確率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| スライム | 32 | 28～35 | 6 | 20% | 10% |
| ゴブリン | 50 | 45～55 | 10 | 30% | 20% |
| ドラゴン | 110 | 99～121 | 20 | 35% | 20% |

確率の残りが通常攻撃です。大技の直後は抽選せず、必ず1ターン息切れになります。

## 予告に合わせて考える

| 敵の予告 | 特徴 | 判断の手掛かり |
| --- | --- | --- |
| 通常攻撃 | 生き残った敵が反撃 | 倒し切れるか、反撃を受けても耐えられるか |
| 大技 | 威力2倍。会心もあり得る | 防御で半減し、次の息切れを使う。直前に防御していないか確認 |
| 防御 | 通常攻撃の被害75%軽減。反撃なし | 強攻撃で突破するか、安全に回復するか |
| 息切れ | 反撃なし。こちらの攻撃が25%強化 | 強攻撃の好機。ただしHPが低ければ回復も有効 |

大技の前に薬を使っても、その直後に大きなダメージを受ける可能性があります。
薬は2個だけなので、HP・予告・敵の残りHP・気力を見て使いどころを決めましょう。

## 解説と調整する場所

詳しい説明は [LEARNING_GUIDE.md](LEARNING_GUIDE.md) にあります。
新しい戦闘ルールは「16. ランダム性と判断を加えた戦闘」で解説しています。

| ファイル | 役割・調整できるもの |
| --- | --- |
| Character.h / Character.cpp | コンストラクタ、HPの下限・上限、ダメージと回復 |
| Player.h / Player.cpp | 勇者の能力・薬の数と回復量・気力 |
| Enemy.h / Enemy.cpp | 設定の読み込み、戦闘用HP、再利用時のリセット |
| EnemyDataTable.h / EnemyDataTable.cpp | データテーブルとシングルトン。敵の基準値と行動確率 |
| EnemyFactory.h / EnemyFactory.cpp | IDから敵を用意するシンプルファクトリー |
| EnemyPool.h / EnemyPool.cpp | 敵を借りて・返して・再利用するオブジェクトプール |
| CombatRandom.h / CombatRandom.cpp | 攻撃の振れ幅・会心確率・乱数生成 |
| GameState.h / Game.h / Game.cpp | 有限状態機械、予告、コマンド処理、防御・強攻撃・息切れの倍率 |
| RPG.cpp | 起動と日本語表示 |

設定表は実行中に変更しません。HPのばらつきは、この戦闘のEnemyだけに適用します。
プールから取り出すたび、能力と行動確率を設定し直します。

## ビルドと確認

C++14・UTF-8を指定しています。日本語を表示するため、/utf-8設定を残してください。
Windowsの文字コードはRPG.cppで設定します。プロジェクト名はConsoleApplication1です。
ビルド生成物はGitの管理対象から除外しています。

HP・回復薬・気力の境界、敵の再利用、乱数の範囲、入力終了を確認しています。
難易度は、本物のGameを固定した1,000種類の乱数開始値で自動操作して比較しました。
この結果は特定の自動操作方針の比較で、すべてのプレイヤーに同じ勝率を保証するものではありません。
通常起動では乱数の開始値を変え、検証時だけGame(seed)で同じ戦闘を再現できます。

| 自動操作方針 | クリア数 / 1,000回 |
| --- | ---: |
| 通常攻撃だけ | 0 |
| 予告を無視し、気力があれば強攻撃、HP40以下で回復 | 49 |
| 大技を防御し、安全なターンに回復、気力を攻撃に使う | 315 |

比較には同じ開始値1～1,000を使っています。選ぶ行動が違うと、乱数を使う順番も変わります。
