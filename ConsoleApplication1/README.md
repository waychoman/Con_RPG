# 小さなコンソールRPG

課題の6つの技術を使った、C++のコンソールRPGです。
勇者がスライム・ゴブリン・ドラゴンを順番に倒すとクリア、勇者のHPが0になるとゲームオーバーです。

## 起動と操作

1. Visual Studioで既存の ConsoleApplication1 ソリューションを開きます。
2. Ctrl + F5（デバッグなしで開始）でビルドして実行します。
3. 数字を入力し、Enterで決定します。

| 画面 | 入力 | 動作 |
| --- | --- | --- |
| タイトル | 1 / 0 | 開始 / 終了 |
| 戦闘 | 1 / 2 / 0 | 攻撃 / 回復薬 / 冒険を中断 |
| 結果 | 1 / 0 | もう一度遊ぶ / 終了 |

勇者はHP100・攻撃力12、回復薬は3個です。回復薬はHPを35回復しますが、最大HPは超えません。
敵が生きていれば、攻撃や回復薬の使用後に反撃されます。敵を倒したターンには反撃されません。
HP満タン・薬がないときの回復操作や無効な入力では、薬もターンも消費しません。
再挑戦するとHP・回復薬・討伐数が元に戻ります。

| 敵 | HP | 攻撃力 |
| --- | ---: | ---: |
| スライム | 30 | 5 |
| ゴブリン | 45 | 9 |
| ドラゴン | 70 | 14 |

攻撃だけではドラゴン戦で倒されるため、回復薬を使うタイミングを考えてみてください。

## 解説を読む順番

詳しい説明と復習表は **[LEARNING_GUIDE.md](LEARNING_GUIDE.md)** にあります。
最初からすべてを覚える必要はありません。まずゲームを遊び、次の順番でコードを読んでください。

1. Character.h / Character.cpp：自分で作ったクラスからの変更と、コンストラクタ・constの復習。
2. Player と Enemy：共通処理を引き継ぐ「継承」。
3. EnemyDataTable：敵の設定とシングルトン。
4. EnemyPool と EnemyFactory：敵を借り、設定して再利用する仕組み。
5. GameState と Game：画面と戦闘の進行。
6. RPG.cpp：ゲームを起動する入り口。

## ファイルと課題の対応

| ファイル | 役割 | 課題の技術 |
| --- | --- | --- |
| RPG.cpp | main関数からGameを起動、日本語表示を設定 | ゲームの入り口 |
| Character.h / Character.cpp | 共通の名前・HP・攻撃力と初期化、ダメージ、回復 | コンストラクタ |
| Player.h / Player.cpp | 勇者の設定と回復薬 | 継承 |
| Enemy.h / Enemy.cpp | 敵の設定を読み込み、再利用時に初期化 | コンストラクタ、再利用 |
| EnemyDataTable.h / EnemyDataTable.cpp | 敵の初期値一覧を1つの共有オブジェクトで管理 | データテーブル、シングルトン |
| EnemyFactory.h / EnemyFactory.cpp | 敵IDから必要な敵を用意する窓口 | ファクトリーパターン（シンプルファクトリー） |
| EnemyPool.h / EnemyPool.cpp | 事前に2体確保し、貸し出し・返却で再利用 | オブジェクトプール |
| GameState.h / Game.h / Game.cpp | タイトル・戦闘・結果・終了を切り替える | 有限状態機械 |

敵の設定は EnemyDataTable.cpp 内の表にあり、外部ファイルは不要です。
プールは敵オブジェクトを所有し、Gameが借りた敵を勝利・敗北・中断・終了時に返します。

## ビルド設定と確認

プロジェクトはC++14とUTF-8を指定しています。日本語の文字列を扱うため、/utf-8 の設定を残してください。
WindowsではRPG.cppがコンソールをUTF-8に設定します。
ソリューション名・プロジェクト名は ConsoleApplication1、main関数のファイル名は RPG.cpp です。
ビルドした実行ファイルや中間ファイルはGitの管理対象から除外しています。

実装後に、ビルドと次の動作を確認しました。

- HPの下限・上限、負数ダメージ、極端に大きい値でのダメージと回復
- 回復薬の個数、HP満タンや薬切れでの操作、再挑戦時の初期化
- データテーブルの共有、未知の敵ID、プールの満杯・二重返却・同じ敵の再利用
- 3体を倒すクリア、ゲームオーバー、再挑戦、途中中断
- 不正な入力の再入力、各画面で入力が途切れた場合の終了
